# Giorgio IM Demo

这是 Giorgio IM 的在线演示站仓库。

GitHub Pages 工作流会自动拉取
[m-finder/giorgio-im](https://github.com/m-finder/giorgio-im)，构建 demo
并发布到 Pages。

## 发布

在仓库 Settings → Pages 中将发布来源设为 **GitHub Actions**。之后推送
到 `main`，或手动运行 `Deploy demo to Pages` 工作流即可。

配置自定义域名时，在 Pages 设置中填写域名。DNS 解析生效后，GitHub 会自动
申请 HTTPS 证书。
